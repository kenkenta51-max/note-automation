# note-automation

note記事作成を自動化するためのプロジェクトです。

## フォルダ構成

- `AGENTS.md` : このリポジトリで作業するAIエージェント向けの指示・ルールをまとめたファイル
- `config/` : 執筆者プロフィールや執筆ルール、リサーチルールなどの設定ファイル置き場
- `workflow/` : 記事作成の各工程（リサーチ〜品質チェック）の手順を記載したファイル群
- `research/` : リサーチ結果を保存する場所
- `drafts/` : 執筆中の下書きを保存する場所
- `output/` : 完成した記事（note投稿用）を保存する場所
